# DeepSeek 腕上

为 **32 位 Android 智能手表** 做的 DeepSeek 聊天客户端：官方 C 端风格的极简 UI、流式对话、深度思考、联网搜索、历史记录，以及专门针对手表麦克风优化的语音输入与上下文纠错。

已在 **OPPO OWW221（Android 11，armeabi-v7a，378×496）** 真机安装验证。

---

## 功能

- **官方风极简 UI**：黑色 AMOLED 界面、DeepSeek 蓝、欢迎页、气泡对话、极简输入栏
- **流式对话**：DeepSeek V4 Flash，边生成边显示，可停止
- **深度思考**：V4 思考模式，折叠显示“已深度思考 · N 秒”，点开看思考过程
- **联网搜索**：输入框左侧地球按钮，开启后先调用 DeepSeek Search API，再基于网页资料回答，并显示“来源 · N 个网页”
- **隐私空间**：菜单进入，四位数字密码；隐私对话只在隐私空间可见，普通历史完全过滤
- **语音模型可选**：SenseVoiceSmall / TeleSpeechASR / 自定义模型
- **v1.7 更新**：修复 LaTeX 数学公式显示，分式/组合数/概率符号/方框/上下标转为可读文本，块级公式居中
- **v1.6 更新**：麦克风单次录音上限从 45 秒提升到 **5 分钟**
- **v1.5 细节**：深色胶囊输入栏、磨砂暗深蓝麦克风、左上角时间、地球双纬线
- **首次适配**：首次启动先调整界面缩放（50%–130%），再进入 4 步使用教程
- **使用教程**：之后可在设置 → 使用教程再次打开；界面缩放可在设置 → 个性化重新调整
- **按住输入框说话**：按住输入框弹出“松手发送”紧凑卡片，松手后自动识别并直接发送；轻点输入框仍是文字键盘；右下角原麦克风保留
- **Markdown 渲染**：标题、粗体、列表、引用、行内代码、代码块
- **历史记录**：本地 SQLite，多会话，重命名、删除、清空
- **语音输入**：
  - 16 kHz 单声道录音
  - 70 Hz 高通滤波
  - 最高约 32 dB 自动增益，专门照顾轻声/悄悄话
  - 能量 VAD，停顿自动结束
  - 硅基流动 SenseVoice 转写
  - DeepSeek 结合最近对话纠正同音字、断句、专有名词
  - 识别结果回填输入框，确认后发送
- **设置**：API Key、接口地址、模型、语音服务、悄悄话增强、上下文纠错、自动朗读
- **手机辅助配置**：手表上显示一个局域网地址，手机浏览器填 Key，不用在 1.4 英寸屏幕上打字
- **朗读**：调用手表自带中文 TTS 朗读回复
- **隐私**：聊天记录和密钥只存手表本地；没有统计、没有广告

## 首次配置（推荐：手机填 Key）

需要两个 Key：

| Key | 用途 | 获取 |
|---|---|---|
| DeepSeek API Key | 聊天、深度思考、上下文纠错 | https://platform.deepseek.com/api_keys |
| 硅基流动 API Key | 语音转文字（ASR） | https://cloud.siliconflow.cn/ |

> DeepSeek 开放平台 API 只提供文本/图片能力，**没有语音转写接口**；官方 App 的语音输入是官方内部服务，未开放到 API。因此语音输入必须再接一个 ASR 服务。默认用硅基流动 **TeleSpeechASR**。

步骤：

1. 手表打开 App
2. 左上角 **菜单 → 设置 → 用手机配置**
3. 手表显示地址，例如：`http://192.168.31.91:8787/?t=xxxxxx`
4. 手机连**同一个 WiFi**，浏览器打开这个地址
5. 填：
   - DeepSeek API Key
   - 语音识别 API Key（硅基流动 Key）
   - 接口地址保持 `https://api.deepseek.com`
   - 语音服务选 **硅基流动 · SenseVoice**
   - 悄悄话增强、上下文纠错保持开启
6. 点 **保存到手表**
7. 看到“配置已保存”后，关闭手机页面和手表配置窗口

注意：手表上的配置窗口要保持打开，手机页面才能保存；页面关闭后本地配置服务会停止。

也可以直接在手表上：**设置 → API Key / 语音识别 Key** 手动输入。

### 语音模型怎么选

在硅基流动里选 **语音转文字（ASR / Transcription）** 分类，不要选文本转语音（TTS）或声音克隆。

- 首选：`TeleAI/TeleSpeechASR`
- 备选：`FunAudioLLM/SenseVoiceSmall`
- CosyVoice、IndexTTS、FishSpeech 等是“让 AI 说话”，不能用来听你说话

App 的默认值已经是 `TeleAI/TeleSpeechASR`，一般不用手改。

## 使用

### 文字

点输入栏，打字，点右侧发送。

### 按住输入框说话（自动发送）

- 在聊天界面直接 **按住输入框**（不要先点开键盘）
- 会弹出一个紧凑的“松手发送”卡片，和右下角麦克风的全屏语音层不同
- **松手** 后自动识别，识别完成直接发送，不需要再点发送
- **轻点** 输入框还是原来的文字输入，会弹出键盘
- **上滑取消**：按住后手指向上滑过一段距离，标题变成“松手取消”，松手丢弃这段录音，不会发送
- 右下角麦克风按钮保留：点它仍是原来的全屏语音输入，识别后回填输入框，需手动发送
- 左上角菜单默认是紧凑的侧滑面板，菜单行轻微错峰淡入，关闭时向左收回；新对话、历史、隐私空间、设置都在里面
- 设置 → 个性化 可以切换侧滑/底部菜单，并可以关闭左上角时间显示
- 新对话切换时旧画面淡出上移，新画面淡入落下
- 第一次配置 API 后，输入框上方会显示一次“点击输入 · 按住说话”，约 4 秒后自动消失，之后不再常驻
- 如果键盘已经弹出，先轻点空白处或按返回收起键盘，再按住输入框

### 语音（右下角麦克风）

点右下角麦克风：

- 正常说：直接说，停顿约 1.6 秒自动结束
- 悄悄话：保持“悄悄话 · 开”，把手表靠近嘴边，用最小的声音说；停顿约 2.4 秒自动结束
- 说完也可以点中间白色按钮手动结束
- 识别完成后文字会回填到输入框，确认后点发送

如果环境很吵，建议开悄悄话模式并靠近嘴边；如果识别总是截断，可以稍微放慢语速。

### 深度思考

点顶部中间 **DeepSeek**，选择：

- **快速对话**：关闭 thinking，响应快
- **深度思考 V4**：开启 thinking，显示思考过程

### 联网搜索

输入框最左侧有一个地球按钮：

- 点一下变蓝 = 开启；再点变灰 = 关闭
- 开启后，每条消息会先请求 DeepSeek Search API，取回最多 5 个网页
- DeepSeek 会基于搜索结果回答，并用 `[1]`、`[2]` 标注来源
- 回答下方显示 **来源 · N 个网页**，点开可看标题并复制链接
- 也可以在 **设置 → 联网搜索** 或顶部 DeepSeek 菜单里开关

搜索按成功请求计费，约 **$0.75 / 1000 次**，单次很便宜；失败、空结果不计费。搜索和聊天共用同一个 DeepSeek Key，不需要额外 Key。

### 语音模型和极速模式

在 **设置 → 语音输入**：

- **识别模型**：默认 `TeleAI/TeleSpeechASR`（更快/更轻），也可切 `FunAudioLLM/SenseVoiceSmall`（高精度）或自定义模型名
- **按住说话快速语音**：默认开启；只影响“按住输入框”自动发送，按住时会跳过纠错，右下角麦克风仍按原设置走
- 如果觉得慢：TeleSpeechASR 已是默认；确认“按住说话快速语音”已开

### 隐私空间

左上角菜单 → **隐私空间**：

- 第一次进入要求设置四位数字密码，需输入两次确认
- 以后每次进入都要输入密码；密码错误会提示重试
- 隐私空间的标题会变成蓝色；这里的对话只在“隐私对话”历史里出现
- 普通历史、普通聊天完全看不到隐私对话
- App 重启后会回到普通空间，需要重新输入密码才能进入
- 退出隐私空间：菜单 → 退出隐私空间
- 设置 → 隐私空间：验证当前密码后可以修改四位密码，或清空整个隐私空间（普通对话保留）

密码使用 PBKDF2 哈希存储，不保存明文。忘记密码只能清除 App 数据，隐私对话也会一起丢失。

### 历史 / 设置

左上角菜单：

- 新对话
- 对话历史
- 设置

长按消息可以复制、朗读、重新生成、删除。

## 架构

```text
手表麦克风
  → 16 kHz PCM + 高通 + AGC + VAD
  → WAV
  → 硅基流动 /audio/transcriptions（SenseVoice）
  → 原始转写
  → DeepSeek 结合最近 8 条消息纠错
  → 回填输入框
  → （可选）DeepSeek /v1/tools/search 取网页
  → DeepSeek /chat/completions（V4，流式）
```

- `DeepSeekClient`：OpenAI 兼容 SSE 流式客户端，支持 V4 `thinking` / `reasoning_effort`
- `SearchClient`：DeepSeek `/v1/tools/search` 客户端，结果会作为系统提示注入回答
- `AudioRecorder`：录音、增益、VAD、WAV 编码
- `AsrClient`：OpenAI 兼容 `/audio/transcriptions` 客户端
- `TranscriptFixer`：DeepSeek 上下文纠错
- `SetupServer`：局域网手机配置页（随机 token，仅配置窗口打开时运行）
- 无原生 `.so`，纯 Java/DEX，因此可直接运行在 32 位 Android 手表上

## 隐私说明

- 聊天记录：本地 SQLite，不上传；普通会话与隐私会话通过 `is_private` 字段隔离
- 隐私密码：PBKDF2-HMAC-SHA1（12,000 轮、随机盐），不保存明文
- API Key：优先 Android Keystore AES/GCM；部分手表 Keystore 不可用时退回本地混淆存储
- 语音：发送到你选择的 ASR 服务（默认硅基流动）
- 文字与搜索词：发送到 DeepSeek 用于搜索和生成回复；搜索来源保存在本地消息表中
- 无统计、无广告、无第三方 SDK
- 手机配置页只监听局域网，需要 URL 里的随机 token，关闭窗口即停止

## 常见问题

**语音提示“没有听清”**
- 靠近手表再说
- 确认“悄悄话 · 开”
- 确认语音识别 Key 是硅基流动的，不是 DeepSeek Key
- 到设置里确认语音服务是“硅基流动 · SenseVoice”

**语音报 401 / 403**
- 语音识别 Key 无效或没有权限

**语音报 404**
- 语音接口地址/模型名不对；恢复默认 `TeleAI/TeleSpeechASR`

**搜索报 401 / 402**
- DeepSeek Key 无效或余额不足；搜索与聊天共用同一个 Key

**搜索没有来源**
- 确认输入框左侧地球按钮是蓝色；搜索无结果时会显示“没有检索到相关网页”

**忘记隐私密码**
- 没有后门；只能清除 App 数据重新开始，隐私对话也会丢失

**隐私对话在普通历史里找不到**
- 这是正常的。请从菜单进入“隐私空间”，输入密码后查看“隐私对话”

**聊天报 401**
- DeepSeek Key 无效

**聊天报模型不存在**
- 设置 → 对话模型，填 `deepseek-flash` 或 `deepseek-v4-pro`

**手机配置页打不开**
- 手机和手表必须同一 WiFi
- 手表配置窗口不要关
- 地址端口可能是 8787/8788/8789/8790，以手表显示为准
- 部分路由器开启了 AP 隔离，需要在路由器里关闭

**键盘打不开**
- 当前版本已修复输入框被列表抢焦点的问题；若仍出现，退出重进

## 已知限制

- 手表端不做离线语音识别；没有网络时不能语音转写
- 语音识别依赖第三方 ASR 服务，效果受麦克风、环境噪声、服务端模型影响
- 深度思考的推理内容由 DeepSeek 返回，长回答在手表上需要滚动查看
- 目前只适配竖屏小屏；未针对圆形屏幕做单独布局
- 隐私空间是应用级隔离：普通界面不会显示，但不是数据库加密；请设置手表锁屏作为额外保护
